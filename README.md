# Vision-monitor_AFK
🎮 Projeto desenvolvido em Python para monitoramento de partidas do Fortnite, utilizando OpenCV para reconhecimento de imagens, PyAutoGUI para automação e Tkinter para interface gráfica. Inclui detecção de telas, controle de teclado, histórico de partidas e código modular, aplicando conceitos de visão computacional e Engenharia de Software.
